# Voice Control

负责人：整体框架与语音开发者。

该目录只负责浏览器端语音交互：

- 麦克风按钮和交互状态。
- 语音采集、识别与转写。
- 将语音意图发送给后端。
- 展示识别结果和错误状态。

禁止在这里保存服务端密钥或直接调用需要私钥的大模型接口。

公共组件和类型必须从 `index.ts` 导出，其他功能不要跨目录引用内部文件。

## Lumi 唤醒模式

- 教学训练阶段可通过 `autoListen` 进入持续待机监听。
- 待机状态只识别唤醒词 `Lumi`，以及常见中文转写“露米、鲁米、路米、卢米”。
- 可以直接说“Lumi，显示骨架”，也可以先说“Lumi”，再在 10 秒内说出需求。
- 未唤醒时的环境声、视频对白和普通指令不得触发动作或调用后端问答。
- 每次需求处理后立即回到待机状态，避免背景音连续触发导航。
